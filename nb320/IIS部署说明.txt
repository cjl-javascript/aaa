EJU 手机营销页——Windows IIS 部署说明
========================================

一、环境要求
1. Windows Server 已启用 IIS。
2. IIS 已安装“静态内容”和“默认文档”功能。
3. 本页面为纯静态网页，不需要安装 Node.js、PHP 或数据库。

二、部署步骤
1. 解压 iis-eju-mobile-landing.zip。
2. 将解压后的全部文件复制到站点目录，例如：
   C:\inetpub\wwwroot\eju-landing\
3. 打开 IIS 管理器，新建网站或在现有网站下新建应用程序。
4. 将物理路径指向上述目录，绑定域名和端口。
5. 给 IIS_IUSRS 账户授予该目录“读取和执行、列出文件夹、读取”权限。
6. 访问网站首页确认页面正常显示。

三、HTTPS
正式收集姓名和手机号前，必须为网站绑定有效 HTTPS 证书，并将 HTTP 请求重定向到 HTTPS。

四、表单接入
当前表单是前端演示模式，不会保存或发送用户信息。
正式使用时，请在 app.js 的表单提交位置接入贵公司的 HTTPS 线索接口。
不要把数据库密码、API 密钥或企业微信密钥写入 app.js；敏感凭据应保存在服务器端。

五、上线前必须替换
1. 机构真实名称、联系方式与网站备案信息。
2. 日本语言学校、教师和学生宿舍的真实授权素材。
3. privacy.html 中的隐私政策占位内容。
4. 课程、服务范围、价格及住宿条件等真实信息。
5. 如果页面收集个人信息，请完成必要的合规审核和安全测试。

六、目录文件
index.html      页面主体
styles.css     页面样式
app.js         弹窗与表单交互
privacy.html   隐私政策模板
web.config     IIS 默认文档、缓存与安全响应头配置

七、常见问题
1. 出现 500.19：检查服务器是否允许读取 web.config；若主机禁止自定义配置，可暂时移走 web.config 后测试。
2. 样式未加载：确认所有文件在同一目录，且站点根目录指向解压后的文件夹。
3. 中文乱码：IIS 应以 UTF-8 返回 HTML、CSS 和 JS；文件本身均为 UTF-8。
4. 表单没有收到数据：这是预期行为，需先接入服务器端线索接口。
